Full-site-editing block theme for a kitchen, bathroom and custom-carpentry renovation company.

== Description ==

Everything is editable in Appearance → Editor:

* Templates: front page, page, landing page (no title), page with quote sidebar, blog, single post, archive, search, 404, project archive, project type archive, single project.
* Template parts: header (top bar + sticky nav), footer, quote call-to-action.
* 13 section patterns (hero, stats bar, services grid, kitchen/bathroom features, process, lightbox gallery, before/after slider, testimonials, FAQ accordion, recent projects, quote CTA, sidebar quote card, page banner).
* 5 full-page patterns offered when you create a new page: Kitchens, Bathrooms, Services, About, Contact.
* Global styles: palette, fluid type scale, spacing scale and shadows in theme.json, plus a "Coastal White" style variation.
* Block styles: Card, Card (lifts on hover), Checklist, Offset frame image, Outline-on-dark button, Eyebrow label.

Pair it with the Elite Carpentry Core plugin for Projects, the quote request form, editable business details and one-click setup.
